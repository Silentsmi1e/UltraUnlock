# UltraUnlock

⚠️ **WARNING: THIS MOD WILL CHANGE YOUR CURRENT SAVE SLOT** ⚠️

UltraUnlock is mainly for devs and shouldn't be used to **FAKE** any progress

UltraUnlock is a **tool that gives you maximum progression** for ULTRAKILL.  
The mod is turned off by default, in the purpose of not overriding anyones save slot
 
To enable UltraUnlock go to ULTRAKILL/BepInEx/config/silentsmilee.ultraunlock.cfg and set EnableUnlock = true

---

## What UltraUnlock Does

When activated, UltraUnlock will:

- ✅ Unlock **all campaign progression**
- ✅ Unlock **Prime Sanctums**
- ✅ Unlock **all weapons and variants**
- ✅ Unlock **all secret missions**
- ✅ Unlock **all unlockables**
- ✅ Fully unlock **Enemy Dictionary / Bestiary**
- ✅ Apply's **P-Ranks** to all levels
- ✅ **Cyber Grind scores** set to 999
- ❌ **DOES NOT TOUCH ARMS** because they are unstable (for now)

---

## Extra Info

- 🔒 **Disabled by default**
- ▶️ **Runs ONCE**, then auto-disables
- 📁 **Creates backups** automatically
- 🚫 Avoids arms cause buggy
